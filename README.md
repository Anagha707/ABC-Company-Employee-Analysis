# ABC Company Employee Data Analysis

## Project Overview
This project focuses on analyzing employee data from ABC Company using Python. The objective is to explore employee distribution, positions, age groups, salary expenditure, and the relationship between age and salary.

## Dataset
- Original dataset: `ABC Company Dataset.csv`
- Cleaned dataset: `ABC_Company_Cleaned.csv`
- Total records: 458 employees

## Tools and Technologies
- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Preprocessing
- Loaded and explored the employee dataset.
- Checked for missing values.
- Replaced the existing Height column values with randomly generated values between 150 and 180.
- Exported the processed dataset as a CSV file.

## Data Analysis
The project includes the following analyses:

1. **Team Distribution:** Analyzed the number and percentage of employees in each team.
2. **Position Segregation:** Examined employee distribution across different positions.
3. **Age Group Analysis:** Identified the predominant employee age group.
4. **Salary Expenditure:** Identified the teams and positions with the highest salary expenditure.
5. **Age and Salary Correlation:** Examined the relationship between employee age and salary.

## Data Visualization
Visualizations were created using Matplotlib and Seaborn, including:
- Bar charts
- Salary expenditure charts
- Age group distribution charts
- Scatter plots
- Correlation heatmap

## Key Insights
The analysis helps understand:
- Employee distribution across teams and positions.
- The predominant age group in the organization.
- Salary expenditure patterns across teams and positions.
- The relationship between employee age and salary.

## Project Files
- `ABC_Company_Employee_Analysis.ipynb` – Jupyter Notebook containing the complete analysis.
- `ABC Company Dataset.csv` – Original dataset.
- `ABC_Company_Cleaned.csv` – Preprocessed dataset.

## Conclusion
This project demonstrates the use of Python for data cleaning, exploratory data analysis, and visualization. It provides insights into employee distribution and salary patterns, helping develop a better understanding of the organization's workforce.
